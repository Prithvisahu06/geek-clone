# GeeksforGeeks Clone

## About This Project
This is a basic frontend clone of the GeeksforGeeks website. It's a static landing page built with just plain HTML and CSS to practice creating responsive web layouts. It uses the site's classic green color scheme and includes the main sections you'd expect to see. 

## Features
* **Navigation Bar:** Includes the logo, a search box, and links for Tutorials, Practice, Jobs, Courses, and GATE.
* **Hero Section:** A simple welcome banner about learning to code and cracking jobs.
* **Content Cards:** Three main cards that display info about Data Structures, Algorithms, and Web Development.
* **Mobile Friendly:** The CSS includes media queries so the page stacks neatly into a single column if you view it on a phone.

## Tech Stack
* HTML5 for the page structure.
* CSS3 for the styling (heavy use of Flexbox).
